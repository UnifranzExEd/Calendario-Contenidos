────────────────────────────────────────────────────────────────────────────────
  ¿QUÉ ES ESTA API?
────────────────────────────────────────────────────────────────────────────────

La API de Estadísticas es un endpoint de solo-lectura que permite consultar 
métricas y conteos del calendario de contenidos UNIFRANZ Online desde cualquier 
sistema externo (dashboards, apps móviles, automatizaciones, reportes, etc.)
sin necesidad de tener sesión de usuario activa.

  ENDPOINT BASE:
  https://TU-DOMINIO.com/api/stats.php

  MÉTODO HTTP:    GET (solo lectura)
  FORMATO:        JSON (UTF-8)
  AUTENTICACIÓN:  API Key por parámetro URL


────────────────────────────────────────────────────────────────────────────────
  AUTENTICACIÓN
────────────────────────────────────────────────────────────────────────────────

Todas las solicitudes requieren la API Key. Se puede enviar de dos formas:

  OPCIÓN A — Query parameter (recomendado para pruebas rápidas):
  ?api_key=uf_stats_2026_key

  OPCIÓN B — Header HTTP Bearer token (recomendado para producción):
  Authorization: Bearer uf_stats_2026_key

  ⚠️  IMPORTANTE: La API Key por defecto es "uf_stats_2026_key"
      Cámbiala en el archivo: /config/auth.php
      Línea: define('STATS_API_KEY', 'TU_NUEVA_CLAVE_SECRETA');

  Si la API Key es incorrecta o no se proporciona, recibirás:
  {
    "success": false,
    "error": "API Key inválida o no proporcionada. Usa ?api_key=YOUR_KEY",
    "hint": "Contacta al administrador para obtener tu API Key"
  }


────────────────────────────────────────────────────────────────────────────────
  PARÁMETROS GLOBALES OPCIONALES
────────────────────────────────────────────────────────────────────────────────

Estos parámetros funcionan con todas las acciones para filtrar resultados:

  PARÁMETRO     TIPO      EJEMPLO          DESCRIPCIÓN
  ─────────     ────      ───────          ───────────
  mes           string    JULIO            Filtrar por mes (en MAYÚSCULAS)
  anio          integer   2026             Filtrar por año (default: año actual)
  pestana       string    pauta            Filtrar por pestaña (usar el slug)

  Meses válidos: ENERO, FEBRERO, MARZO, ABRIL, MAYO, JUNIO, JULIO,
                 AGOSTO, SEPTIEMBRE, OCTUBRE, NOVIEMBRE, DICIEMBRE

  Slugs de pestañas comunes: pauta, redes, instagram, facebook, tiktok
  (consultar al administrador para la lista completa de slugs disponibles)


────────────────────────────────────────────────────────────────────────────────
  ESTRUCTURA DE RESPUESTA ESTÁNDAR
────────────────────────────────────────────────────────────────────────────────

Todas las respuestas exitosas incluyen estos campos base:

  {
    "success": true,
    "generated_at": "2026-07-29T18:00:00-04:00",   ← Timestamp de generación
    ...datos específicos de la acción...
  }

  Los errores siempre incluyen:
  {
    "success": false,
    "error": "Descripción del error"
  }

────────────────────────────────────────────────────────────────────────────────
  ACTION 1: resumen
────────────────────────────────────────────────────────────────────────────────

  DESCRIPCIÓN:
  Vista consolidada del mes. Muestra el total de piezas y las clasifica
  en categorías de progreso (espera, proceso, listas, publicadas) además
  de un desglose por nivel de prioridad.
  Por defecto usa el MES ACTUAL si no se especifica el parámetro "mes".

  URL DE EJEMPLO:
  GET /api/stats.php?action=resumen&api_key=uf_stats_2026_key

  CON FILTROS:
  GET /api/stats.php?action=resumen&mes=JULIO&anio=2026&api_key=uf_stats_2026_key

  RESPUESTA:
  {
    "success": true,
    "generated_at": "2026-07-29T18:00:00-04:00",
    "periodo": {
      "mes": "JULIO",
      "anio": 2026
    },
    "resumen": {
      "total_piezas": 47,       ← Total de piezas en el mes
      "en_espera": 12,          ← En elaboración + Redacción
      "en_proceso": 8,          ← En revisión + Producción + Corrección
      "hechas": 18,             ← Aprobadas + Diseñadas + Listas
      "publicadas": 9           ← Estado = Publicado
    },
    "prioridades": {
      "alta": 5,
      "media": 32,
      "baja": 10
    },
    "detalle_por_estado": [
      { "estado": "En elaboración", "cnt": 8 },
      { "estado": "Redacción",      "cnt": 4 },
      { "estado": "En revisión",    "cnt": 5 },
      ...
    ]
  }

  CUÁNDO USAR:
  → Dashboard ejecutivo de resumen mensual
  → Widget de inicio de sesión
  → Reporte semanal automatizado


────────────────────────────────────────────────────────────────────────────────
  ACTION 2: piezas_por_mes
────────────────────────────────────────────────────────────────────────────────

  DESCRIPCIÓN:
  Desglose completo del año mes a mes. Devuelve todos los 12 meses con
  sus conteos y un sub-desglose por estado. Ideal para gráficas de barras
  o líneas de evolución anual.

  URL DE EJEMPLO:
  GET /api/stats.php?action=piezas_por_mes&anio=2026&api_key=uf_stats_2026_key

  CON FILTRO DE PESTAÑA:
  GET /api/stats.php?action=piezas_por_mes&anio=2026&pestana=pauta&api_key=uf_stats_2026_key

  RESPUESTA:
  {
    "success": true,
    "generated_at": "...",
    "anio": 2026,
    "meses": [
      {
        "mes": "ENERO",
        "total": 38,
        "publicadas": 35,
        "en_proceso": 0,
        "estados": [
          { "estado": "Publicado", "cantidad": 35 },
          { "estado": "Aprobado",  "cantidad": 3  }
        ]
      },
      {
        "mes": "FEBRERO",
        "total": 42,
        "publicadas": 40,
        ...
      },
      ...12 meses en total...
    ]
  }

  CUÁNDO USAR:
  → Gráfica de evolución anual de producción
  → Comparación mes a mes
  → Reporte anual de desempeño

    "generated_at": "...",
    "periodo": { "mes": "JULIO", "anio": 2026 },
    "tabs": [

        "pestana": "PAUTA",
        "slug": "pauta",
        "total": 15,

  CUÁNDO USAR:

  → Identificar qué pestaña tiene más piezas pendientes

  └──────────┘  └──────────┘  └──────────┘  └──────────┘

  PASO 3 — Mostrar distribución por prioridad:
  Alta: ████ 5
  Media: ████████████████████████████████ 32

────────────────────────────────────────────────────────────────────────────────
  FLUJO 3: Alerta de Prioridades Críticas
────────────────────────────────────────────────────────────────────────────────

  OBJETIVO: Disparar alertas si hay piezas de Alta Prioridad sin publicar

  PASO 1 — Consultar piezas por prioridad:
  ┌──────────────────────────────────────────────────────────────────────────┐
  │ GET /api/stats.php?action=piezas_por_prioridad&mes=JULIO&api_key=KEY     │
  └──────────────────────────────────────────────────────────────────────────┘

  PASO 2 — Extraer las piezas ALTA que NO están publicadas:
  alta = respuesta.prioridades[0]  // prioridad: "Alta"
  pendientes = alta.total - (cantidad_publicadas_en_alta)

  PASO 3 — Si pendientes > 3: enviar alerta (email, Slack, WhatsApp, etc.)

  CÓDIGO PYTHON DE EJEMPLO:
  ┌─────────────────────────────────────────────────────────────────┐
  │ import requests                                                  │
  │                                                                  │
  │ API_KEY = "uf_stats_2026_key"                                   │
  │ BASE    = "https://tudominio.com/api/stats.php"                 │
  │                                                                  │
  │ r = requests.get(BASE, params={                                  │
  │     "action":  "piezas_por_prioridad",                          │
  │     "mes":     "JULIO",                                         │
  │     "api_key": API_KEY                                           │
  │ })                                                               │
  │                                                                  │
  │ data = r.json()                                                  │
  │ for p in data["prioridades"]:                                    │
  │     if p["prioridad"] == "Alta":                                 │
  │         publicadas = next((e["cantidad"] for e in p["estados"]  │
  │                     if e["estado"] == "Publicado"), 0)          │
  │         pendientes = p["total"] - publicadas                     │
  │         if pendientes > 3:                                       │
  │             print(f"ALERTA: {pendientes} piezas Alta sin pub")  │
  └─────────────────────────────────────────────────────────────────┘

  FRECUENCIA SUGERIDA: Cada hora durante días laborables

────────────────────────────────────────────────────────────────────────────────
  FLUJO 5: Reporte Automático Semanal (Google Sheets / Excel)
────────────────────────────────────────────────────────────────────────────────

  OBJETIVO: Llenar automáticamente una hoja de cálculo con datos de producción

  CÓDIGO PYTHON COMPLETO:
  ┌─────────────────────────────────────────────────────────────────┐
  │ import requests, json                                            │
  │                                                                  │
  │ API_KEY = "uf_stats_2026_key"                                   │
  │ BASE    = "https://tudominio.com/api/stats.php"                 │
  │                                                                  │
  │ def consultar(action, **kwargs):                                 │
  │     params = {"action": action, "api_key": API_KEY, **kwargs}  │
  │     r = requests.get(BASE, params=params, timeout=10)           │
  │     r.raise_for_status()                                         │
  │     return r.json()                                              │
  │                                                                  │
  │ # 1. Resumen del mes actual                                      │
  │ resumen = consultar("resumen")                                   │
  │ print("Total:", resumen["resumen"]["total_piezas"])              │
  │ print("Publicadas:", resumen["resumen"]["publicadas"])           │
  │                                                                  │
  │ # 2. Evolución del año                                           │
  │ anual = consultar("piezas_por_mes", anio=2026)                  │
  │ for mes in anual["meses"]:                                       │
  │     print(f"{mes['mes']}: {mes['total']} piezas")               │
  │                                                                  │
  │ # 3. Por red social                                              │
  │ redes = consultar("piezas_por_red", mes="JULIO")                │
  │ for red in redes["redes"]:                                       │
  │     print(f"{red['red_social']}: {red['total']}")               │
  └─────────────────────────────────────────────────────────────────┘

================================================================================
  NOTAS DE SEGURIDAD
================================================================================

  1. CAMBIA LA API KEY antes de poner en producción.
     Archivo: /config/auth.php
     Línea:   define('STATS_API_KEY', 'NUEVA_CLAVE_AQUI');

  2. La API Key de ejemplo "uf_stats_2026_key" es PÚBLICA en esta guía.
     No la uses en producción tal cual.

  3. La API es de solo lectura. No puede crear, editar ni eliminar contenidos.

  4. Los datos se filtran automáticamente — nunca expone contenidos eliminados.

  5. Si necesitas más seguridad, agrega HTTPS (SSL) en el servidor web.

  6. Puedes agregar restricción por IP en el servidor nginx/apache si lo deseas.
